# 🍔 Sistema de Delivery — Front-end

## 📌 Sobre o projeto

O **Sistema de Delivery** é um projeto acadêmico desenvolvido para a disciplina de **Desenvolvimento de Sistemas de Informação**.

O sistema tem como referência o funcionamento de plataformas de delivery, como o **iFood**, utilizando seus conceitos e funcionalidades como base para o desenvolvimento de uma solução própria.

O projeto tem como objetivo aplicar, na prática, conhecimentos adquiridos ao longo do curso, envolvendo desenvolvimento web, integração com APIs, banco de dados, modelagem de sistemas e regras de negócio.

> 🚧 **Status:** Em desenvolvimento

## 🎯 Objetivo

Desenvolver uma aplicação web de delivery que permita aos usuários interagir com as principais funcionalidades planejadas para o sistema, utilizando uma interface intuitiva e integrada ao back-end.

## 🛠️ Tecnologias

As tecnologias previstas para o desenvolvimento do Front-end são:

* React
* Node.js
* VS Code

> A lista de tecnologias poderá ser atualizada conforme o desenvolvimento do projeto.

## 📋 Funcionalidades previstas

### 👤 Usuário

* Cadastro de usuário
* Login
* Autenticação
* Integração com serviços externos de autenticação

### 📍 Local

* Cadastro de local
* Integração com Google Maps API

### 🔄 Integração

* Comunicação com a API do Back-end
* Consumo de dados e serviços disponibilizados pelo sistema
