Política de Privacidade - EntregaFood

O EntregaFood é um projeto acadêmico desenvolvido para fins educacionais.

Ao utilizar o login com Google ou Facebook, o sistema pode receber informações básicas autorizadas pelo usuário, como nome, e-mail e foto de perfil.

Esses dados são utilizados exclusivamente para autenticação e identificação do usuário dentro da aplicação.

O EntregaFood não comercializa nem compartilha dados pessoais com terceiros para fins publicitários.

O usuário pode solicitar a exclusão de seus dados a qualquer momento.
